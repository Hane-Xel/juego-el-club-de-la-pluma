# El club de la pluma

## Descripción 

Es un juego de peleas estilo Super Smash Bros con toques de juegos de pelea clasicos como Street Fighter. El juego tiene un enfoque aéreo con el sistema de ataques de Super Smash Bros, o sea, un botón de ataque y uno de especial que cambia según la dirección a la que este mirando el personaje y una mecánica en la que la mayoría de personajes podrán volar cuando se vuelve a apretar el botón de salto

## Instalación y compilación del proyecto

Se debe descargar la carpeta de ElClubDeLaPluma que encontrarás en nuestro Github https://github.com/Hane-Xel/juego-el-club-de-la-pluma.
 Una vez descargada la carpeta tenés que entrar a un programa de edición de código java como puede ser Eclipse e importarlo como proyecto ya existente de gradle. De ahí debes entrar a la carpeta lwjgl3, luego src/main hasta java/miEmpresa/LPOO/lwjgl3, en donde deberás ejecutar el archivo lwjgl3Launcher.java.
